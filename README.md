# Ravinder Kunchala — DevOps & Cloud Portfolio

A minimal, editorial-style portfolio inspired by the reference website shared by Ravinder, redesigned around a DevOps / Cloud Engineer profile.

## Run locally

No build tools are required.

```bash
python3 -m http.server 8080
```

Open `http://localhost:8080`.

Or use VS Code Live Server.

## Before deploying

1. Replace `YOUR_EMAIL@example.com` in `index.html` with your real email.
2. Review the experience dates and project wording.
3. Optionally add a `resume.pdf` and link it from the navigation.
4. Update the LinkedIn/GitHub links if needed.

## Deploy

This is a static site and can be deployed to:
- Netlify
- GitHub Pages
- AWS S3 + CloudFront
- Vercel

## Design

The visual language uses:
- oversized typography
- monospace technical labels
- numbered sections
- subtle borders
- light/dark mode
- responsive layout
- animated cursor
- scroll reveal hooks
